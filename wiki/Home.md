# Welcome to XenoNPCs

XenoNPCs adds **native NPCs made for DragonMineZ**. You place them with a wand, shape them in an
in-game editor, and they fight with DragonMineZ's own stats, forms, auras, skills and ki attacks.
They can trade, guard, follow you, give quests, run a bank, carry you across the map, talk in speech
bubbles, and run scripts you write.

## What you need

| | Version |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.233 or newer |
| DragonMineZ | 2.1.3 or newer |
| GeckoLib, TerraBlender, Curios | the versions DragonMineZ asks for (it needs all three) |

CustomNPCs or My NPCs are **optional**: when one is installed, XenoNPCs adds its DragonMineZ features
to those NPCs too.

> **XenoNPCs and XenoPixels Network cannot be installed together.** XenoPixels already contains
> everything in XenoNPCs; the game will refuse to start and tell you to remove one.
